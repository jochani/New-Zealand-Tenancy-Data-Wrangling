# New-Zealand-Tenancy-Data-Wrangling
A uni repostory for the course DATA422
## Dataset

### Source

This project uses the New Zealand Airbnb listings dataset published by
Inside Airbnb.

- Dataset: listings.csv
- Geographic coverage: New Zealand
- Dataset date: 19 June 2026
- Source: Inside Airbnb – Get the Data
- Description: Summary information and metrics for Airbnb listings,
  suitable for data analysis and visualisation.

The dataset is stored locally by each team member and is not included
in this GitHub repository because of its size.

## Important Columns

| Column | Meaning |
|---|---|
| id | Unique identifier for the Airbnb listing |
| name | Name or title of the listing |
| host_id | Unique identifier for the host |
| host_name | Name of the host |
| neighbourhood_group | Larger geographic grouping, where available |
| neighbourhood | Area or local authority associated with the listing |
| latitude | Geographic latitude of the property |
| longitude | Geographic longitude of the property |
| room_type | Type of accommodation, such as entire home or private room |
| price | Listing price per night in New Zealand dollars |
| minimum_nights | Minimum number of nights required for a booking |
| number_of_reviews | Total number of reviews received by the listing |
| last_review | Date of the most recent review |
| reviews_per_month | Estimated average number of reviews per month |
| calculated_host_listings_count | Number of listings operated by the host |
| availability_365 | Number of days the listing is available in the next 365 days |
| number_of_reviews_ltm | Number of reviews received in the last 12 months |
| license | Licence or registration information, where available |
